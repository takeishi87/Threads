# 外国人労働者の雇用契約書の作り方と必須記載事項【2026年版】

**公開日: 2026年6月25日**

## ─── はじめに ───

「日本語が話せるから大丈夫だろう」——そう考えて口頭説明だけで採用を進めた知人の会社で、入社1ヶ月後に給与の計算方法をめぐる行き違いが起きた。「契約書に書いてあったはずなのに、なぜ伝わっていなかったのか」と双方が首をかしげたそうだ。

原因は契約書そのものにあった。日本語のみで書かれた、日本人向けの雇用契約書をそのまま流用していたのだ。専門用語が並ぶ書面を前に、本人は内容を十分に理解せずに署名していた。

外国人労働者の雇用契約書は、日本人向けの契約書をそのまま流用すればよいというものではない。労働基準法で定められた必須記載事項に加えて、外国人労働者特有の確認事項（在留資格の範囲・就労可能時間・帰国時の対応など）を盛り込む必要がある。本記事では、雇用契約書（労働条件通知書）に何を書けばよいのか、初心者の採用担当者にも分かるように、項目ごとに整理して解説する。

## ─── 第1章：そもそも「雇用契約書」と「労働条件通知書」の違いって何？ ───

まず混同しやすい2つの文書の違いを整理しておこう。

| 項目 | 雇用契約書 | 労働条件通知書 |
|------|-----------|---------------|
| 法的な位置づけ | 会社と労働者が合意して結ぶ「契約」 | 会社が労働者に労働条件を「通知」する書面 |
| 作成義務 | 法律上の作成義務はない（任意） | 労働基準法第15条により作成・交付が義務 |
| 署名・押印 | 会社・労働者の双方の署名（捺印）が必要 | 労働者側の署名は不要（会社からの通知のため） |
| 実務での扱い | 多くの企業で労働条件通知書の内容を兼ねた「雇用契約書」として一本化されている | 単独で交付されることもあるが、契約書に統合する企業も多い |

**実務でこう使える**：多くの中小企業では、労働条件通知書に記載すべき必須事項をすべて盛り込んだ「雇用契約書」を1つ作成し、双方の署名を取ることで、通知義務と契約の合意を同時に満たす運用にしている。本記事でもこの一本化された形式を前提に解説する。

### before/after：口頭説明だけのケースと、契約書を整備したケース

| 項目 | Before（口頭説明のみ） | After（多言語契約書を整備） |
|------|----------------------|---------------------------|
| 労働条件の理解度 | 本人の日本語力に依存し、認識のズレが発生しやすい | 母国語または英語の対訳付きで誤解を防止 |
| トラブル発生時の対応 | 「言った・言わない」の水掛け論になりやすい | 書面に署名があるため、双方の合意内容が明確 |
| 入管手続きへの影響 | 必要事項が漏れていると在留資格審査で指摘される可能性 | 必須記載事項が揃っていれば手続きがスムーズ |

## ─── 第2章：労働基準法で定められた必須記載事項一覧 ───

労働基準法第15条および同法施行規則第5条により、労働条件通知書（雇用契約書）には以下の事項を記載することが義務付けられている。このうち①〜⑥は**必ず書面で**交付しなければならない「絶対的明示事項」、それ以外は口頭でもよいが書面が望ましい「相対的明示事項」とされている。

| No. | 区分 | 記載事項 |
|-----|------|---------|
| ① | 絶対的明示事項 | 労働契約の期間 |
| ② | 絶対的明示事項 | 有期労働契約を更新する場合の基準（更新の有無・回数の上限など） |
| ③ | 絶対的明示事項 | 就業の場所・従事する業務の内容（変更の範囲を含む） |
| ④ | 絶対的明示事項 | 始業・終業の時刻、休憩時間、休日、休暇、交替制勤務に関する事項 |
| ⑤ | 絶対的明示事項 | 賃金の決定・計算・支払方法、賃金の締切り・支払いの時期、昇給に関する事項 |
| ⑥ | 絶対的明示事項 | 退職に関する事項（解雇の事由を含む） |
| ⑦ | 相対的明示事項 | 退職手当の定めが適用される労働者の範囲、退職手当の決定・計算・支払方法等 |
| ⑧ | 相対的明示事項 | 臨時に支払われる賃金（ボーナス等）、最低賃金額に関する事項 |
| ⑨ | 相対的明示事項 | 労働者に負担させる食費・作業用品等に関する事項 |
| ⑩ | 相対的明示事項 | 安全・衛生に関する事項 |
| ⑪ | 相対的明示事項 | 職業訓練に関する事項 |
| ⑫ | 相対的明示事項 | 災害補償・業務外の傷病扶助に関する事項 |
| ⑬ | 相対的明示事項 | 表彰・制裁に関する事項 |
| ⑭ | 相対的明示事項 | 休職に関する事項 |

**現場での確認方法**：採用担当者は契約書を作るとき、まず①〜⑥が漏れていないかをチェックリスト形式で確認するとよい。1つでも欠けていると労働基準法違反となり、行政指導の対象になる可能性がある。

## ─── 第3章：外国人労働者特有の追加記載事項 ───

労働基準法の必須事項に加えて、外国人労働者を雇用する場合は以下の事項も契約書（または別紙）に明記しておくことが望ましい。これらは法律上の絶対的な義務ではないものの、在留資格審査や実務上のトラブル防止の観点から、厚生労働省も記載を推奨している。

| 確認事項 | 内容 | 記載しないとどうなるか |
|---------|------|----------------------|
| 在留資格・就労制限の範囲 | 在留資格（例：技術・人文知識・国際業務、特定技能など）の種類と、その資格で認められる業務内容の範囲 | 契約上の業務が在留資格の範囲外だと、出入国在留管理局の審査で不許可・指摘の対象になりうる（要確認：個別の審査結果は事案により異なる） |
| 在留期間・契約期間の整合性 | 雇用契約の期間と在留期間（在留カードの期限）の整合性 | 在留期間を超える契約期間を結んでも、その期間分の就労が保証されるわけではない |
| 帰国旅費の負担 | 契約終了時・解雇時の帰国旅費の負担者（技能実習生については法令上の負担義務あり） | 負担者が不明確だと、契約終了時にトラブルになりやすい |
| 公的保険・税金の取り扱い | 社会保険・雇用保険・所得税の取り扱いと、本人負担分の説明 | 給与から保険料・税金が差し引かれる理由を理解されず、賃金未払いと誤解されるケースがある |
| 緊急連絡先・宗教・生活習慣への配慮事項 | 緊急時の連絡先、宗教上の配慮（礼拝時間・食事制限など）の取り扱い | 必須記載事項ではないが、定着支援の観点から記載しておくと安心材料になる |

**こんな指摘を受けることも**：在留資格「技術・人文知識・国際業務」で採用した社員に、契約書で定めた業務内容と異なる単純作業ばかりを担当させていたケースでは、在留期間更新時に業務内容との不整合を指摘される可能性がある（要確認：個別の取り扱いは出入国在留管理局の判断による）。契約書の業務内容と実際の業務を一致させておくことが重要だ。

## ─── 第4章：多言語対応はどうすればいいか ───

労働条件通知書（雇用契約書）は、外国人労働者が内容を理解できる言語で交付することが望ましいとされている。厚生労働省は「外国人労働者向けモデル労働条件通知書」を多言語で公開しており、英語・中国語・韓国語・ポルトガル語・スペイン語・タガログ語・ベトナム語・インドネシア語・タイ語・ネパール語・クメール語・ミャンマー語・モンゴル語の各言語版が利用できる（[厚生労働省 外国人労働者向けモデル労働条件通知書（英語）](https://www.mhlw.go.jp/new-info/kobetu/roudou/gyousei/kantoku/040325-4.html)）。

| 対応方法 | メリット | デメリット |
|---------|---------|-----------|
| 厚労省のモデル通知書をそのまま使う | 無料・必須記載事項が網羅済み・多言語版あり | 自社独自の規定（手当・服装規定など）は別途追記が必要 |
| 日本語＋対訳言語の二段組み契約書を自作 | 自社の実情に合わせて柔軟に作成できる | 翻訳の正確性を自社で担保する必要がある |
| 翻訳会社・行政書士に依頼する | 法的な表現の正確性が高い | コストがかかる（要確認：依頼先・言語により費用は異なる） |
| やさしい日本語＋ルビ・図解を併用する | 日本語学習中の人にも段階的に理解を促せる | 専門的な法律用語の正確な伝達には限界がある |

**作成時のヒント**：厚生労働省は人事・労務でよく使う用語約420語について、やさしい日本語と9言語で定義・例文を検索できる用語集を公開している。契約書の表現に迷ったら、こうした公的な用語集を参照しながら作成すると、独自翻訳による誤訳リスクを減らせる（[厚生労働省 外国人向け多言語説明資料](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/koyou/jigyounushi/tagengoyougosyu.html)）。

**ポイント**：労働条件通知書には外国人労働者側の署名は不要だが、雇用契約書として双方合意の形をとる場合は、本人が内容を理解した上で署名できるよう、対訳版を渡すことが望ましい。

## ─── 第5章：在留資格別に気をつけたい記載のポイント ───

在留資格の種類によって、契約書で特に注意すべき点が異なる。

| 在留資格 | 契約書で特に注意すべき点 |
|---------|------------------------|
| 技術・人文知識・国際業務（技人国） | 学歴・実務経験に対応した業務内容であることを明記。単純作業のみの契約にしない |
| 特定技能 | 分野ごとの業務範囲、特定技能所属機関としての支援計画との整合性、日本人と同等以上の報酬であることの明記 |
| 技能実習 | 技能実習計画に記載された作業内容との一致、帰国旅費の負担者（技能実習法に基づく基本方針等において実習実施者が負担する旨が示されている） |
| 特定活動（インターンシップ等） | 就労が許可される期間・時間の上限、教育機関との協定内容との整合性 |

**契約書チェックの観点**：特定技能で採用する場合、「日本人が同様の業務を行う場合と同等以上の報酬であること」が制度上の要件となるため、契約書の賃金欄は同職種の日本人従業員の賃金水準と比較しても説明できる内容にしておく必要がある（要確認：報酬水準の妥当性は分野・地域・経験により個別に判断される）。

## ─── 第6章：地味だけど見落としやすい記載項目 ───

| 項目 | 見落とされやすい理由 | 対応のヒント |
|------|---------------------|-------------|
| 試用期間中の労働条件の違い | 本採用後と条件が変わる場合、試用期間中の条件も明記が必要 | 試用期間の有無・期間・条件差を契約書に明記する |
| 更新の有無の表現 | 「更新する場合がある」のような曖昧な表現はトラブルの元 | 更新の判断基準（業績評価・出勤率など）を具体的に書く |
| 変更の範囲（就業場所・業務内容） | 2024年4月の労基法改正で明示が義務化された比較的新しい項目 | 転勤・配置転換の可能性がある場合は変更範囲を明記する |
| 退職時の手続き | 退職届の提出期限・引き継ぎ方法が書かれていないケースが多い | 退職を希望する場合の申し出期限（例：1ヶ月前）を明記する |

**見直しのきっかけに**：就業場所や業務内容の「変更の範囲」の明示は2024年4月から義務化された比較的新しいルールであり、古い契約書テンプレートをそのまま使っている企業では漏れがちな項目だ。テンプレートを更新済みか、今一度確認しておきたい。

## ─── 第7章：契約書作成の落とし穴ケーススタディ ───

### ケース1：日本語のみの契約書にサインさせてしまった

来日直後で日本語が片言の技能実習生に、日本語のみの契約書へ署名を求めたケース。本人は「内容が分からないままサインした」と後になって話し、監理団体を通じて説明のやり直しが必要になった。対策として、契約締結時には対訳版を用意し、本人の母国語または理解できる言語で内容を説明する時間を設けることが重要だ。

### ケース2：賃金の支払い方法の記載が曖昧だった

「給与は月末締め、翌月支払い」という記載だけで、具体的な支払日（例：翌月25日）を明記していなかったケース。本人が「いつ給料がもらえるのか分からない」と不安を感じ、相談窓口に問い合わせる事態になった。賃金の締切日・支払日は具体的な日付まで明記するのが望ましい。

### ケース3：在留資格の業務範囲と実際の業務がずれていた

契約書には「営業企画業務」と記載していたが、実際には倉庫での仕分け作業を主に担当させていたケース。在留期間更新の際に業務内容の不整合が問題となり、説明資料の追加提出を求められた（要確認：個別の審査結果は事案により異なる）。契約書に記載した業務内容と実際の業務を一致させることが不可欠だ。

## ─── 第8章：契約書作成チェックリスト ───

契約書を作成・確認する際に使えるチェックリストをまとめた。

- 労働契約の期間が明記されているか
- 就業の場所・業務内容・変更の範囲が明記されているか
- 始業・終業時刻、休憩、休日、休暇が明記されているか
- 賃金の決定方法・計算方法・支払日が具体的な日付で明記されているか
- 退職に関する事項（解雇事由を含む）が明記されているか
- 更新の有無とその判断基準が明確に書かれているか
- 在留資格の種類と業務内容が整合しているか
- 帰国旅費の負担者が明記されているか（技能実習の場合は特に重要）
- 本人が理解できる言語（対訳版）で内容を確認できるようになっているか
- 試用期間がある場合、その期間中の条件も明記されているか

## ─── まとめ ───

外国人労働者の雇用契約書は、日本人向けの契約書をそのまま流用するのではなく、労働基準法上の必須記載事項（契約期間・就業場所・業務内容・賃金・退職に関する事項など）を漏れなく盛り込んだ上で、在留資格の範囲との整合性や多言語対応といった外国人特有の配慮を加える必要がある。

**今日からできること**：まずは厚生労働省が公開している「外国人労働者向けモデル労働条件通知書」をダウンロードし、自社の契約書と項目を1つずつ照らし合わせてみてほしい。漏れている項目があれば、本記事のチェックリストを使って優先順位の高いものから追記していくとよい。

**明日試してほしいこと**：既存の外国人従業員がいる場合は、契約書の業務内容欄と実際の業務内容が一致しているかを確認してみよう。在留期間の更新前に見直しておくことで、思わぬ指摘を防げる。
